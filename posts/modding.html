Modding

November 05, 2026

I started modding for a week right now, and it have been a pretty joy to do it.

The reason i want to make a post about it is how it can enhance for people who wants to start in game developing.

It takes a lot of abilities that can be enhanced by doing modding for games.

Why modding?

First off, i want to answer in why modding can enhance your game development skills.

Modding requires a lot of skills, depending in what you want to do.

Take as a example a custom car in Gmod. First you would likely to do some modelling and coding in GLua (A modified version of Lua for GMod).

Doing this you already started doing some practice of coding and modelling, which can be transfered in the future when you use a real game engine/framework.

I started making some mods in SM64Coop DX, which helped me learn some the syntax of Lua. Which now i understand some of the code of GLua.

Which games to mod?

There is plenty of options, however choose a game to focus on and start doing it.
